# Oracle Agent Memory 연결 설계

사용자가 명시적으로 저장한 기억을 새 ADB에 보관하고, 다음 세션과 프로세스 재시작 뒤에도 같은 사용자만 조회할 수 있게 합니다. 기존 접수·승인 DB는 업무 상태를 관리합니다.

2026-11-05 사용자 요청: 새 ADB 생성. 서울 / Joungmin.Ko, 전용 26ai OLTP ADB, 2 ECPU·20GB, 자동 확장 끔·라이선스 포함. TLS 연결과 VM 공인 IP 허용 목록을 사용합니다. 관리자·스키마 설치 계정과 실행 계정을 분리하고 비밀값은 Git에 저장하지 않습니다. SDK 26.8.0을 고정합니다.

Foundation은 공급자 SDK 연결과 사용자 범위 저장·검색 DTO를 제공합니다. 앱은 명시적인 기억 저장 요청, 인증 주체와 세션의 일치, 실행 기록을 관리합니다. SDK 자동 추출·자동 관계 생성은 끄며, 검색 결과는 명령이나 승인으로 해석하지 않습니다. 별도 사용자 ID 입력을 신뢰하지 않고 인증 Actor에서 서버가 범위를 계산합니다. 기억 원문은 Companion 추적에 넣지 않고 작업 종류·결과·건수·지연만 보냅니다.

검증: 새 ADB에서 저장·의미 검색, 다른 사용자 접근 차단, 재연결과 앱 재시작 후 복원, 공급자 장애 시 안전한 오류, 실제 API 호출과 Companion 화면을 확인합니다. 동시 쓰기·분산 중복 방지와 전체 플랫폼 수준의 메모리 수명 관리는 별도 범위이며 검증 없이 완료로 표시하지 않습니다.
