# 기존 Hello Agent에 SDD 연결

기존 agent.py의 validate → execute → run 흐름을 재사용합니다. 표준 라이브러리로 실행 가능한 test_agent.py만 이번 명세의 검증 범위에 넣고, FastAPI 웹과 OCI 인증·관측 기능은 별도 검증 범위로 둡니다.

REQ-001은 ZoneInfo의 도시별 시간대를 사용합니다. REQ-002는 입력과 실행 경계에서 허용 목록을 확인합니다. REQ-003은 demo_decision으로 계정 없는 선택 경로를 제공합니다. 명세·작업 지시서·검토 보고서는 실제 모델을 호출하지 않습니다.

## 변경 요청: 지원 도시 목록

변경 전에 기존 명세 기준의 작업 지시서를 생성합니다. 지원 도시를 묻는 데모 입력은 인자 없는 list_cities 도구로 연결합니다. 실행 결과는 기존 ZONES에서 도시와 시간대를 가져오고 답변도 이 결과로 만듭니다. 인자를 전달하거나 정의되지 않은 도구를 호출하면 거부합니다. 기존 시간·인사·거부 동작을 유지합니다. OCI 모델 선택용 프롬프트에도 새 도구를 설명하되 실제 모델 연동 성공을 주장하지 않습니다.

완료 조건: 목록의 3개 도시와 시간대 일치, demo에서 모델 미사용, 목록 도구의 추가 인자 거부, 기존 6개 회귀 테스트 유지. 작업 지시서 생성 후 이 Codex가 구현하며 독립된 다른 개발자나 자동 외부 도구 연동으로 보고하지 않습니다.

## 영문 도시 목록 요청 확장

`demo_decision`의 도시 목록 판별에서만 `message.strip().casefold()`를 사용하고 기존 한국어 허용 집합에 `list cities`, `supported cities`를 추가합니다. 전체 문자열의 집합 포함 여부로 비교하므로 접두·접미 문구와 내부 공백 변형은 허용하지 않습니다. 기존 시간·인사 분기에는 원래 입력을 그대로 전달합니다. 도구 검증·실행·답변 생성 및 OCI 경로는 변경하지 않습니다.

기존 8개 테스트를 유지하고 영문 성공·정규화 경계와 부분 일치 실패 테스트 2개를 추가합니다. 기존 구현에서 영문 성공 사례가 실패하는 것을 먼저 확인한 뒤 전체 로컬 테스트로 검증합니다. 실제 모델과 외부 서비스는 호출하지 않습니다.
