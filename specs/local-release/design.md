# 검증한 ZIP의 실행·복구 실습

완료 조건: 기존 출장비 앱을 A로 검증·패키징하고 CLI --version을 추가한 B에서 새 테스트 실패→구현→통과를 확인합니다.
두 ZIP에 코드·명세·테스트 근거를 넣고 각각 다른 폴더에 풀어 CLI를 실제 실행합니다.
B의 실행 파일을 고의로 손상시킨 뒤 해시 차이와 실행 실패를 확인하고 A를 다시 선택해 정상 계산을 확인합니다.
각 단계의 ZIP SHA-256·패키지 파일 해시·실행 결과·선택 버전을 summary.json에 연결합니다.

기존 package_travel_demo의 파일 허용 목록과 검증을 재사용합니다. 원본 프로젝트는 변경하지 않습니다.
출력 디렉터리는 새 경로만 허용하고, 압축 검증 후 새 실행 폴더에 풀어 사용합니다.
current.json은 다음 CLI 실행에 사용할 릴리스 선택 기록이며 상시 서비스 트래픽 전환 기능이 아닙니다.
복구 시 이전 ZIP 해시와 실행 폴더 해시가 일치하는지 확인하고 정상 계산 후 선택합니다.
실패 실습의 모든 조작은 새 출력 폴더의 B에 한정합니다.

범위: Python 표준 라이브러리, 로컬 CLI, 가상 출장비 규정. OCI·모델·운영 배포·DB 복원·무중단 전환은 제외합니다.
