# 검증한 앱을 패키징하고 이전 버전으로 복구하기

**명세 변경부터 테스트·ZIP 전달·별도 폴더 실행·이전 버전 복구까지 한 번에 확인합니다.** 출장비 CLI를 사용한 로컬 실습이며 Python 3.12 이상과 이 저장소만 있으면 됩니다. 패키지 설치·OCI 계정·모델 호출은 필요하지 않습니다.

## 실행

저장소 루트에서 실행합니다. 모든 변경과 고의 장애는 새 출력 폴더 안에서만 일어나며 원본 앱은 수정하지 않습니다.

```sh
mkdir -p .run
python3 -S scripts/local_release_demo.py --output .run/local-release
```

정상 완료하면 `LOCAL_RELEASE_PASS`, `source_unchanged: true`, `active_release: a`를 확인할 수 있습니다. 다시 실행할 때는 `.run/local-release-2`처럼 새 출력 이름을 사용하세요. 실패 시 종료 코드 1과 생성된 단계별 근거를 확인합니다. 원본 파일 변경이 감지되면 종료 코드 2입니다.

## 확인하는 순서

| 단계 | 실제로 수행하는 일 | 확인 결과 |
|---|---|---|
| A 준비 | 기존 명세에 연결된 테스트를 실행하고 ZIP 생성 | 현재 통과 근거와 소스·명세·테스트가 ZIP에 포함 |
| A 실행 | ZIP 해시를 검증하고 새 폴더에 풀어 CLI 실행 | 2박 → 200000원, 모델 미사용 |
| B 변경 | 복사한 명세에 CLI `--version` 조건과 테스트 추가 | 기존 구현에서 새 테스트 실패 |
| B 구현 | CLI에 버전 출력을 추가하고 재검증·패키징 | 전체 연결 테스트 통과, 새 ZIP 생성 |
| B 실행 | 다른 폴더에 풀어 계산·버전 출력 확인 | 기존 계산 유지, `travel-demo-b` 출력 |
| 장애 주입 | B의 실행 파일을 고의로 바꿈 | 패키지 파일 해시 불일치, 실행 종료 코드 9 |
| 복구 | A의 ZIP·실행 파일 해시와 계산을 재확인하고 A 선택 | 선택된 A에서 다시 200000원, 모델 미사용 |

장애 주입은 설치 후 파일 손상 시나리오입니다. 테스트를 통과한 코드에 실제 운영 장애가 발생했다는 기록이 아닙니다. B의 원본 ZIP은 정상 상태로 보존되고 압축을 푼 실행 파일만 손상됩니다.

## 결과물 읽기

- `release-a.zip`, `release-b.zip`: 각각 검증한 버전의 실행물입니다. 기존 [출장비 패키지 도구](../offline-package/README.md)를 사용합니다.
- `evidence-a.json`, `evidence-b-red.json`, `evidence-b.json`: A 통과·새 조건 실패·B 통과의 요구별 기록입니다.
- `source/`: 명세·테스트·구현을 변경한 복사본입니다. 최종 B 소스가 남습니다.
- `runtime-a/`, `runtime-b/`: ZIP을 풀어 실제 실행한 폴더입니다. B는 실습 종료 후 고의 손상 상태로 남습니다.
- `current.json`: 다음 CLI 실행에 사용할 버전 선택 기록입니다. 최종 값은 A입니다.
- `summary.json`: ZIP SHA-256, 근거 파일 이름, 단계별 실행 결과와 복구 결과를 연결합니다.

각 ZIP의 `PACKAGE.json`에는 포함 파일의 해시가 있으며 `test-evidence.json`에는 실행 당시 소스·명세·테스트 해시가 있습니다. 이를 통해 어떤 검증 결과로 만든 실행물인지 비교할 수 있습니다. 파일 해시는 서명이나 배포 승인을 대신하지 않습니다.

복구된 실행물을 직접 확인할 수도 있습니다.

```sh
python3 -S .run/local-release/runtime-a/examples/enterprise-ai-web/cli.py 2
python3 -S scripts/package_travel_demo.py verify .run/local-release/release-a.zip
```

ZIP 검사는 테스트를 실행하지 않습니다. 실행 폴더의 파일을 직접 바꾸면 원래 패키지 근거가 그 변경까지 검증하지 않습니다.

## 완료 범위

2026-11-10 macOS / Python 3.15.0에서 실제 ZIP 생성·별도 폴더의 CLI 실행·의도적인 실패·A 복구를 확인했습니다. 자동 테스트에서도 같은 사이클, 원본 보존, 기존 출력 덮어쓰기 거부와 잘못된 계산 결과의 실패 판정을 확인합니다.

이로써 **이 출장비 예제의 로컬 변경→검증→패키징→실행→복구 사이클**을 재현할 수 있습니다. 고정 예제 실습이며 임의 앱의 릴리스 관리 기능이 아닙니다. `current.json`은 웹 트래픽이나 실행 중인 프로세스를 전환하지 않습니다. 무중단 배포, 운영 데이터·DB 복구, 클라우드 배포, 브라우저 화면 검증과 고객 인수는 범위 밖입니다. 웹·API·MCP 제공 방식이나 특정 개발 도구를 강제하지 않습니다.
