# 검증한 로컬 앱 전달

수신자가 저장소 전체를 받지 않고도 검증한 출장비 웹·CLI 예제를 실행할 수 있도록 ZIP을 만든다.

- 범위는 이 예제의 로컬 실행이다. Python 3.12 이상은 수신자가 준비한다. 범용 배포 시스템이나 OCI 배포를 주장하지 않는다.
- 고정된 허용 파일 목록(앱 코드·화면·테스트·명세)과 현재 파일에 맞는 통과 테스트 근거만 포함한다. .run·인증·환경 파일과 전체 저장소를 복사하지 않는다.
- 현재 명세의 연결 파일과 패키지 파일 목록이 다르면 명시적으로 실패해 목록 검토를 요구한다. 링크 검사, 근거 freshness, 복사한 바이트 해시를 확인한다.
- RUN.md에 시작 명령을 제공하고 PACKAGE.json에 각 파일의 SHA-256을 기록한다. 기존 ZIP을 덮어쓰지 않는다.
- verify는 압축을 풀거나 코드를 실행하지 않고 파일 목록·해시·경로를 확인한다. 자체 서명이나 작성자 신뢰를 보증하지 않는다.
- 새 임시 폴더에서 ZIP을 풀고 CLI 및 포함된 웹·CLI 테스트를 실행한다. stale 근거·파일 누락·변조·외부 경로·덮어쓰기를 거부한다.
