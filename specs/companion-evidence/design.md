# Companion에서 개발·실행 근거 이어 보기

사용자는 현재 OCI 접속 범위에서 명세·검증·패키지·실행·추적 연결을 한 화면에서 확인합니다.
첫 입력은 검증한 로컬 출장비 릴리스 A/B입니다. 실제 OCI 배포나 Langfuse trace 연결이 없으면 미연결로 표시합니다.
기존 합성 trace를 다른 앱의 배포 근거로 붙이지 않습니다.

Launchpad exporter는 검증된 ZIP 해시와 포함된 테스트 파일 해시를 대조하고, 요구 본문·기록 시간·릴리스 SHA를 JSON 스냅샷으로 내보냅니다.
Companion은 설정된 로컬 JSON만 읽고 프로필·테넌시·사용자·demo·리전·구획이 일치하는 항목만 표시합니다.
GET 화면은 테스트·클라우드 작업·외부 URL 요청을 실행하지 않습니다. 링크는 http/https 또는 지정한 Companion 내부 경로만 허용합니다.
스냅샷의 시간과 근거 한계를 표시하고 실시간 운영 상태로 표현하지 않습니다.

완료 조건: 로그인 필요, 범위 격리, 잘못된 링크 거부, HTML 이스케이프, 누락/손상 파일 처리,
로컬 릴리스의 명세→테스트→패키지→로컬 실행 연결 및 OCI 배포/trace 미연결 표시.
운영 이전·자동 시작·Tailscale 설정 정식 반영은 이번 범위에 포함하지 않습니다.

## 실제 배포·trace 기록 연결

Hello Agent의 기존 Companion Job 검증 결과를 별도 항목으로 가져옵니다. 기록의 배포 ID와 OCI 조회 결과 ID·구획·리전이 같고, 앱 health/응답 버전과 응답/관측 trace ID가 같을 때만 연결합니다. 배포 성공만으로 업무 성공을 판정하지 않습니다. Job 완료와 업무 검사, 같은 trace의 AGENT·GENERATION·TOOL 관측을 따로 검사합니다.

읽기 전용으로 조회한 OCI 배포 결과와 Langfuse 관측 스냅샷을 사용합니다. 새 모델 호출·배포·trace 공개는 수행하지 않습니다. trace 상세 주소는 조회한 프로젝트 ID와 trace ID로 구성하고, 배포 상세 주소는 검증한 pipeline/run ID로 구성합니다. 임의 내부 URL·쿼리는 허용하지 않습니다.

기존 실행 기록은 명세·소스·이미지 digest를 연결하는 해시를 갖고 있지 않습니다. 현재 소스 명세를 과거 배포의 명세로 표시하지 않으며 이 부분은 미연결로 남깁니다. 파일을 가져오는 것과 서명된 증명, 현재 서비스 정상 상태는 구분합니다. 누락·다른 배포·다른 trace·버전 불일치·미완료 Job·관측 누락을 거부하는 테스트와 실제 JSON→화면 배선을 검증합니다.

## 릴리스 수집과 대조

관측 API의 metadata에서 네 개 해시만 허용 목록으로 수집합니다. 다른 메타데이터와 입력·출력 본문은 내보내지 않습니다. 누락과 잘못된 형식을 구분하고 원래 값을 오류 메시지에 넣지 않습니다.

선택 입력인 릴리스 JSON·원본 명령 근거·소스 루트를 함께 제공하면 생성기와 동일한 알고리즘으로 현재 파일을 재검사합니다. health·채팅 응답·모든 관측의 네 해시가 동일한 경우에만 업무 명세 원문과 명세·소스·검증 해시를 표시합니다. 누락, 불일치, 소스 변경/실패 근거는 별도 상태이며 배포·trace 조회 성공을 명세 검증 완료로 승격하지 않습니다. 파일 경로·내용·예외는 오류 상태에 노출하지 않습니다. 이미지 내용 대조와 실시간 상태 조회는 별개입니다.

실제 OTLP payload를 API 응답 형식의 로컬 대역으로 변환하여 수집→대조→화면 JSON까지 검사합니다. 과거 실제 기록에는 새 해시를 추가하지 않습니다. 합성 성공/실패 사례를 실제 운영 기록으로 등록하지 않습니다.
