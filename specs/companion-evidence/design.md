# Companion에서 개발·실행 근거 이어 보기

사용자는 현재 OCI 접속 범위에서 명세·검증·패키지·실행·추적 연결을 한 화면에서 확인합니다.
첫 입력은 검증한 로컬 출장비 릴리스 A/B입니다. 실제 OCI 배포나 Langfuse trace 연결이 없으면 미연결로 표시합니다.
기존 합성 trace를 다른 앱의 배포 근거로 붙이지 않습니다.

Launchpad exporter는 검증된 ZIP 해시와 포함된 테스트 파일 해시를 대조하고, 요구 본문·기록 시간·릴리스 SHA를 JSON 스냅샷으로 내보냅니다.
Companion은 설정된 로컬 JSON만 읽고 프로필·테넌시·사용자·demo·리전·구획이 일치하는 항목만 표시합니다.
GET 화면은 테스트·클라우드 작업·외부 URL 요청을 실행하지 않습니다. 링크는 http/https 또는 지정한 Companion 내부 경로만 허용합니다.
스냅샷의 시간과 근거 한계를 표시하고 실시간 운영 상태로 표현하지 않습니다.

완료 조건: 로그인 필요, 범위 격리, 잘못된 링크 거부, HTML 이스케이프, 누락/손상 파일 처리,
로컬 릴리스의 명세→테스트→패키지→로컬 실행 연결 및 OCI 배포/trace 미연결 표시.
운영 이전·자동 시작·Tailscale 설정 정식 반영은 이번 범위에 포함하지 않습니다.
