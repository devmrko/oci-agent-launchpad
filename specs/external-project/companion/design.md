# 외부 프로젝트 연결 설계

원본 공개 저장소의 별도 checkout에 명세와 unittest 연결 파일만 추가합니다.
기존 pytest 함수 두 개는 fixture가 없는 순수 assert이므로 unittest에서 직접 호출합니다.
pytest fixture·플러그인·매개변수화를 일반적으로 지원하는 방식은 아닙니다.

추가 변경 제안: /와 /healthz는 정상 상태, 나머지 경로는 JSON 404를 반환합니다.
기존 명세에 작업 요청을 연결한 뒤 새 경계 테스트 실패를 확인하고 구현합니다.
테스트 서버는 루프백의 임의 포트를 사용하고 종료합니다. OCI·컨테이너 배포는 하지 않습니다.
