# 직접 작성한 요구로 명세 시작하기

개발자가 특정 챗봇이나 합성 데모에 의존하지 않고 자신의 요구를 SDD 파일로 만들 수 있어야 한다.

- 제목, 목적, 하나 이상의 요구를 직접 입력한다. Python 표준 라이브러리만 사용한다.
- 새 저장소 내부 폴더에 spec.md, design.md, tasks.md, traceability.json을 생성한다. 기존 경로와 저장소 외부 경로는 거부한다. 생성 전 입력을 모두 검증한다.
- REQ-001부터 순서대로 ID를 부여한다. 요구 문장은 원문 그대로 보관하고 합격 조건은 미작성으로 표시한다.
- 설계와 작업은 작성·검토할 초안으로 생성한다. 구현과 테스트 연결은 빈 목록으로 남긴다. 검토 기록이나 통과 테스트를 만들어 내지 않는다.
- 기존 링크 검사기는 초안의 빈 연결을 실패로 판정한다. 사용자가 코드·테스트를 작성하고 연결하면 기존 테스트 근거 도구를 사용할 수 있다.
- 범위는 새 명세의 시작이다. 요구 분석·코드 생성·기존 명세 변경·배포는 수행하지 않는다.

검증: 입력 오류 시 미생성, 기존 파일 보존, 외부 경로 차단, 빈 연결의 검사 실패, 실제 구현과 테스트 연결 후 실행 성공.
