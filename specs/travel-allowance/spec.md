# 출장 숙박비 명세

직원이 숙박 일수를 입력하면 가상 규정에 따른 한도를 즉시 확인합니다. 규정 계산은 일반 웹 기능이며 AI 설명은 선택합니다. 특정 챗봇·IDE·클라우드 계정 없이 명세를 읽고 기본 기능을 구현·시험할 수 있어야 합니다.

2026년 11월 9일 SDD 방향 적용의 첫 예제입니다. 아래 요구는 기존 학습 예제를 바탕으로 작성한 합성 요구이며 실제 고객 인터뷰나 고객 승인 기록이 아닙니다. 명세 변경은 Git diff로 검토합니다.

## REQ-001 규정 계산

숙박은 정수 1~10박입니다. 1박당 한도 100,000원을 곱한 정수 금액과 계산식을 반환합니다. 2박은 200,000원이며 식비·교통비는 제외합니다. 문자열·소수·불리언·범위 밖 입력을 거부합니다.

## REQ-002 계정 없는 실행

Python 표준 라이브러리만으로 `--offline` 실행이 가능해야 합니다. 오프라인 모드에서 OCI 라이브러리·인증·네트워크 호출 없이 계산할 수 있어야 합니다. 응답에는 AI 사용 여부를 명시합니다. 실제 OCI 요청 경로는 거부합니다.

## REQ-003 선택적 AI

OCI 모드는 명시적 프로젝트·리전·인증을 사용합니다. 기존 규정 계산 기능과 별도로 AI 설명과 코드 도구를 선택할 수 있습니다. 실패 시 일반 계산 결과를 실제 AI 응답으로 표시하지 않습니다.

## REQ-004 결과 판정

AI 답변 수신, 계산 도구 실행, 도구 출력과 예상 금액 일치를 구분합니다. 빈 답변·도구 실패·잘못된 금액을 검증 성공으로 표시하지 않습니다. 최종 자연어 문장의 의미 검증은 사람의 검토 범위입니다.

## REQ-005 로컬 접근과 호출 제한

서버는 loopback에서만 실행합니다. 외부 Origin·잘못된 접근 토큰 요청을 거부합니다. OCI 호출은 실행당 최대 10회이며 실패도 차감합니다. 일반 규정 계산은 유료 호출 한도를 사용하지 않습니다.

## REQ-006 터미널에서 같은 규정 사용

사용자는 웹 서버를 시작하지 않고 CLI에 숙박 일수를 전달해 JSON 계산 결과를 받습니다. 정상 입력은 정수 1~10박이며 결과 필드는 웹의 규정 계산과 같습니다. 잘못된 입력은 종료 코드 2와 표준 오류 메시지를 반환하고 표준 출력에 성공 결과를 쓰지 않습니다. OCI 인증·외부 패키지·모델 호출은 필요하지 않습니다. CLI 문자열 인자를 정수로 변환한 뒤 웹과 같은 공통 계산 함수를 사용합니다.

## 제외와 후속

지급·신청·승인·실제 회사 규정·영구 저장은 제외합니다. 이번 SDD 예제의 OCI 앱 배포는 미실행입니다. 기존 Hello Agent 배포 기록을 이 앱의 배포 성공으로 재사용하지 않습니다. 인터뷰 도구의 export를 요구 초안으로 가져오는 연결, 명세 변경 영향 분석, OCI 배포 증거 연결은 후속 작업입니다.
