# 규정 계산과 선택적 AI의 설계

코드 변경 전에 작성한 첫 SDD 확장 설계입니다. 기존 `examples/enterprise-ai-web`을 재사용하며 별도 포털·DB·프레임워크를 추가하지 않습니다.

REQ-001: 순수 함수 `estimate(nights)`가 입력 검증과 계산을 담당합니다. UI와 API가 같은 산식을 사용하며 LLM 출력으로 규정을 결정하지 않습니다.

REQ-002: `--offline`은 OCI 준비 점검을 생략합니다. `POST /api/estimate`는 표준 라이브러리만 사용합니다. `POST /api/run`은 오프라인에서 409로 거부합니다. UI에는 규정 계산 버튼만 제공하며 오프라인임을 표시합니다.

REQ-003: 기존 OCI 시작 명령은 유지합니다. OCI 모드에도 규정 계산 버튼이 있고 AI 설명 버튼은 추가 선택입니다. 두 결과는 `model_used`와 별도 상태 문구로 구분합니다.

REQ-004: 기존 `assess` 판정을 유지합니다. 규정 계산은 계산식·숫자를 직접 반환합니다. 모델 결과를 HTML로 삽입하지 않고 텍스트로 표시합니다.

REQ-005: 두 POST 경로에 기존 Host·Origin·토큰 검사를 적용합니다. OCI만 잠금·횟수 제한을 적용합니다. 입력은 경로별 필드를 엄격히 검사합니다.

변경 범위는 이 예제와 명세·검사 도구·README입니다. 다른 인터뷰·배포·Foundation 작업은 변경하지 않습니다. 로컬 테스트가 통과해도 OCI 배포·운영 인증·전체 SDD 자동화 완료로 표시하지 않습니다.

## 명세를 다른 도구에서 사용하기

`spec.md`가 요구, 이 문서가 기술 선택, `tasks.md`가 작업, `traceability.json`이 요구별 소스·테스트 위치를 제공합니다. Markdown·JSON은 일반 파일로 편집하며 도구 전용 DB가 정본이 되지 않습니다. 이 파일명을 특정 SDD 제품의 자동 호환 규약으로 주장하지 않습니다.

검사 도구는 링크·테스트 이름의 존재를 확인합니다. 요구의 완전성이나 테스트가 업무 의도를 충분히 검증하는지는 사람이 리뷰합니다. 실제 테스트 실행은 별도 명령이며 조회·검사만으로 PASS 증거를 만들지 않습니다.

## 같은 규정을 웹과 CLI에서 재사용

REQ-006: 기존 estimate 함수를 allowance.py로 옮기고 server.py와 cli.py가 함께 import한다. 공통 모듈은 HTTP·CLI·OCI에 의존하지 않는다. CLI는 인자 변환과 출력만 담당하며 정상 결과는 stdout JSON, 오류는 stderr와 종료 코드 2로 구분한다. 서버는 기존 함수 이름을 import하므로 기존 테스트·HTTP 동작을 유지한다.

이는 이 예제의 구현 선택이며 다른 프로젝트의 필수 구조가 아니다. MCP 서버는 이번 범위에 포함하지 않는다. 공통 모듈을 모든 기존 요구의 구현 의존 파일에 추가해 변경 검사와 예제 복사에 포함한다. CLI 요구에는 공통 함수·CLI·실제 subprocess 테스트를 연결한다. 완료 기준은 기존 HTTP 테스트 유지, CLI의 정상·경계·잘못된 입력 검증, 전체 SDD 체험 재현이다.

## 로컬 서버 초기화의 이름 조회 제거

CI의 macOS에서 별도 프로세스 기반 체험이 실패하여 로컬 서버 초기화 경로를 점검한다. 표준 HTTPServer.server_bind는 socket.getfqdn을 호출한다. 이 예제는 127.0.0.1에만 바인딩하므로 TCPServer의 바인딩을 사용하고 서버 이름·포트를 실제 바인딩 주소에서 설정하여 외부 이름 조회에 의존하지 않게 한다. 회귀 테스트는 getfqdn 호출을 실패시키는 환경에서도 서버가 정상 생성되는지 확인한다. 실패한 전체 체험 테스트에는 정제된 테스트 결과 JSON을 함께 출력한다.

## 14박 상한 변경

REQ-001·REQ-006의 공통 입력 범위를 14박으로 확대합니다. [변경 요청과 합격 조건](change-14-nights.md)에 따라 웹 선택지·HTTP 오류 안내·CLI 도움말을 함께 갱신하며, 11·14박 허용과 15박 거부를 함수·HTTP·CLI에서 확인합니다.
