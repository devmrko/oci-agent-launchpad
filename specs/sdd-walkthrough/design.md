# SDD 전체 흐름 재현 예제 설계

처음 방문한 개발자가 계정이나 패키지 설치 없이 요구 초안, 검토 기록, 명세 연결, 테스트 근거와 변경 감지를 재현할 수 있도록 한다.

- 명령 하나가 고정된 합성 출장비 자료와 명세에 연결된 파일만 새 작업 폴더에 복사한다. 원본 구현은 수정하지 않는다.
- 합성 요구 REQ-001에 데모용 검토 기록을 만들고 기존 구현 명세 REQ-001에 명시적으로 연결한다. 사람의 실제 검토나 고객 승인을 주장하지 않는다. REQ-002와 미정 질문은 그대로 남긴다.
- 기존 도구를 재사용해 테스트를 실행하고, 인터뷰 변경과 구현 파일 변경을 각각 시연한다.
- 인터뷰만 바꾸면 기존 테스트는 여전히 통과 기록이지만 요구 재검토가 필요하다. 구현 파일을 바꾸면 테스트 근거도 오래된 상태가 된다.
- 요약 JSON은 각 관찰 결과와 예상 상태 일치 여부를 포함한다. 하나라도 불일치하면 실패 종료한다. 기존 출력 폴더는 덮어쓰지 않는다.
- 새로운 의존성·네트워크·OCI 호출·배포는 없다. Git에 추적되는 원본 파일을 별도 폴더에 복사한 환경에서도 실행을 검증한다.
