# 공개 예제의 자동 검증

다른 개발자가 코드를 수정했을 때 계정 없는 예제와 명세 연결이 깨지는지 확인할 수 있어야 한다.

- main push, pull request, 수동 실행에서 GitHub Actions가 Ubuntu와 macOS의 Python 3.12로 검증한다.
- 앱 테스트, SDD 도구 테스트, 명세 링크 검사, 합성 자료 전체 체험을 실행한다. 각 단계의 실패를 작업 실패로 전파한다.
- Python 패키지 설치와 OCI 자격 증명·모델 호출·배포를 요구하지 않는다. GitHub 실행 환경 준비에는 네트워크를 사용한다.
- 권한은 contents: read로 제한하고 checkout 인증을 유지하지 않는다. pull_request_target이나 배포 작업을 추가하지 않는다. 외부 Actions는 확인한 커밋 SHA로 고정한다.
- 결과는 해당 커밋의 Actions 실행 로그로 확인한다. 전체 체험의 DEMO_PASS는 합성 시나리오의 정상 동작이며 고객 승인이나 배포 성공이 아니다.
- 프로젝트 전체를 검증했다고 주장하지 않는다. 자동 검증 범위는 scripts의 SDD 도구와 enterprise-ai-web 예제이다. 브랜치 보호 설정은 변경하지 않는다.

완료 기준: 동일 명령 로컬 통과, 공개 저장소의 실행 기록에서 두 운영체제 작업의 실제 결과 확인. 실행 서비스에서 차단되면 이유를 보고하고 성공으로 표기하지 않는다.
