# 작업 지시서를 실행 명령에 연결

수신할 개발 도구를 고정하지 않고 사용자가 명시한 실행 파일과 인자에 작업 지시서를 전달한다.

- 원본 root와 최신 handoff를 확인한 후, baseline에 연결된 파일만 새 workspace에 복사한다. 원본 프로젝트로 변경을 자동 적용하지 않는다.
- 명령은 CLI의 -- 뒤에 명시적으로 지정한다. 문서에서 명령을 추출하지 않고 shell=False로 실행한다. {task}와 {workspace} 인자 치환만 지원한다.
- 실행 상태, 종료 코드, 시간 초과, 변경 파일과 diff를 로컬 결과로 기록한다. 명령 성공은 구현 승인이나 테스트 통과가 아니다.
- 기존 출력은 거부한다. 오래된 baseline은 실행 전에 거부한다. 복사한 파일 해시가 기준과 일치하는지 재확인한다.
- POSIX의 별도 프로세스 그룹으로 실행하고 시간 초과·종료 후 같은 그룹에 남은 프로세스를 정리한다. 작업 폴더 분리는 보안 샌드박스가 아니다. 선택한 명령은 실행 계정의 권한과 환경을 가진다.
- stdout·stderr는 저장하지 않는다. 결과 파일에는 명령 인자를 저장하지 않는다. 새 심볼릭 링크·너무 큰 산출물은 diff 수집 실패로 기록한다. 외부 내용을 따라 읽지 않는다.
- workspace의 반환 결과는 기존 spec_evidence와 developer_handoff report의 --root로 검증한다. 검증 도구 자체는 workspace의 도구가 아니라 호출한 Launchpad의 도구를 사용한다.

이번 검증은 명세에 연결된 작은 Python 프로젝트와 결정적인 로컬 테스트 어댑터로 수행한다. 실제 외부 AI 개발 서비스·모델·배포 호출은 하지 않는다. 자동 병합·독립 개발자 검토 완료를 주장하지 않는다.
