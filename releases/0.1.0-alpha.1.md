# OCI Agent Launchpad 0.1.0-alpha.1 — 엔지니어 동행형 알파

고객의 작은 에이전트를 함께 만들고 OCI에 배포하여 실제 동작과 관측을 확인하는 개발·검증용 알파입니다. 저장소는 비공개로 유지합니다.

- 시작 안내: [ALPHA.md](https://github.com/devmrko/oci-agent-launchpad/blob/main/ALPHA.md)
- 고정 조합: 첨부한 `0.1.0-alpha.1.json`의 Launchpad·Companion·Python Foundation·Hello Agent 기준을 사용합니다.
- OCI Companion은 이 알파의 필수 빌드·배포·상태 조회 도구입니다. 배포된 에이전트는 Companion과 독립적으로 실행됩니다.
- 기본 경로: Functions 소스 빌드 → Managed Build 이미지 패키징 → OCIR → OKE → 웹 호출 → Langfuse 관측. Memory는 업무에 따라 선택합니다.
- 확인한 결과: 실제 모델·도구 응답, Langfuse 입력/출력, Companion 앱·Pod·노드 조회, Companion 검증 Job PASS. 고정 Companion의 깨끗한 체크아웃 156개 테스트 통과.

현재는 릴리스 초안입니다. 새 고객 환경의 독립 설치·정리·복구 재현과 OSS 배포 조합 고정은 남아 있습니다. Job 결과 자동 수집, 고객용 인증, 실패 추적·재전송, 전체 AgentCore 기능 동등성은 제공하지 않습니다. 기존 환경의 사설 이미지와 계정 접근이 자동 제공되는 설치 패키지는 아닙니다.
